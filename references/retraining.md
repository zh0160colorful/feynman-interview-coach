# Targeted Retraining

## Purpose

Turn interview feedback into continuous improvement.

## Retraining Loop

Identify weakness → Design exercise → Practice again → Evaluate improvement

## Weakness Categories

- Knowledge gap
- Explanation gap
- Reasoning gap
- Structure gap
- Evidence gap
- Communication gap
- Confidence gap

## Exercise Types

### Concept Repair
Use Feynman explanation to rebuild understanding.

### Question Drill
Practice similar interview questions.

### Challenge Drill
Answer harder follow-up questions.

### Reflection
Summarize lessons learned.
