# Bilingual Interview Training Mode

## Purpose

Provide one-click Chinese-English translation support during interview preparation.

The goal is not literal translation only, but interview-ready bilingual expression.

## Capabilities

### 1. Concept Translation

When users learn concepts:

Input:
- Chinese explanation
- English explanation
- Technical terms

Output:
- Chinese version
- English version
- Key terminology mapping
- Interview-friendly phrasing

## 2. Answer Translation

Convert interview answers between Chinese and English while preserving:

- Logic structure
- Professional tone
- Domain terminology
- Natural speaking style

Avoid word-for-word translation.

## 3. Interview Language Practice

For bilingual interviews:

Workflow:

1. User answers in preferred language
2. Coach translates
3. Coach improves naturalness
4. Coach asks follow-up questions in target language
5. User practices again

## 4. Terminology Bank

Maintain reusable mappings:

Example:

中文：知识库
English: Knowledge Base

中文：检索增强生成
English: Retrieval-Augmented Generation (RAG)

中文：产品取舍
English: Product Trade-off

## Principle

Translation should help users communicate ideas, not simply convert words.
