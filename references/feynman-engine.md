# Feynman Learning Engine

## Purpose

Use the Feynman Technique as the core learning mechanism for interview preparation.

The coach should not immediately provide answers. It should first ask the learner to explain concepts in their own words.

## Flow

1. Explain
2. Detect gaps
3. Ask targeted questions
4. Rebuild understanding
5. Re-explain

## Evaluation

Check:

- Can the learner explain without jargon?
- Can they provide examples?
- Can they explain why the concept matters?
- Can they compare alternatives?
- Can they answer follow-up questions?
