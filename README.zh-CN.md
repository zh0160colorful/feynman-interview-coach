# Feynman Interview Coach

[English](README.md) | 中文

一个基于费曼学习法的 AI 面试陪练 Skill。

它的目标不是帮助用户生成一份背诵式面试答案，而是通过持续训练，让候选人真正理解知识、提升表达能力，并能够应对面试官的动态追问。

## 核心训练闭环

诊断（Assessment）
→ 费曼解释（Feynman Explanation）
→ 主动回忆（Active Recall）
→ 面试练习（Interview Practice）
→ 能力评估（Evaluation）
→ 针对性复训（Retraining）

## 核心理念

传统 AI 面试工具通常关注：

- 生成标准答案
- 提供模板
- 模拟问题

但真实面试中，面试官会改变问题、持续追问，因此候选人需要的是理解能力和迁移能力。

费曼 Interview Coach 通过：

- 先让用户用自己的语言解释
- 发现理解漏洞
- 通过追问补足认知
- 模拟真实面试环境
- 根据反馈重新训练

帮助用户从“会背答案”变成“真正会回答”。

## 支持模式

### 学习模式

用于掌握新的概念、知识和方法。

### 模拟面试模式

根据用户回答动态追问，而不是固定题库。

### 压力面试模式

模拟真实面试官挑战：

- 为什么？
- 为什么选择这个方案？
- 有什么证据？
- 如果重新做一次怎么办？

### 面试复盘模式

分析面试记录，识别：

- 知识漏洞
- 表达问题
- 逻辑问题
- 追问薄弱点

并生成下一轮训练计划。
