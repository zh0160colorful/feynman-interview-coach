# 费曼面试教练

[English](README.md) | 简体中文

一个基于费曼学习法的 AI 面试陪练 Skill。

## 项目定位

Feynman Interview Coach 的目标不是帮助用户生成一份背诵式面试答案，而是通过持续训练，让候选人真正理解知识、提升表达能力，并能够应对面试官的动态追问。

核心理念：

> 不要背答案，而是理解到可以回答不同形式的问题。

## 核心训练闭环

诊断（Assessment）
→ 费曼解释（Feynman Explanation）
→ 主动回忆（Active Recall）
→ 面试练习（Interview Practice）
→ 能力评估（Evaluation）
→ 针对性复训（Retraining）

## 核心能力

### 费曼学习

- 先让用户用自己的语言解释
- 发现理解漏洞
- 通过追问加深理解
- 重新组织表达

### 面试陪练

- 动态模拟面试
- 根据回答继续追问
- 模拟真实面试官视角

### 能力评估

从多个维度评价：

- 理解程度
- 表达结构
- 逻辑推理
- 案例支撑
- 应变能力

### 双语训练

支持：

- 中英文互译
- 面试回答翻译
- 专业表达优化
- 双语模拟面试

## 支持场景

- 学习新知识
- 准备岗位面试
- 模拟真实面试
- 分析面试表现
- 制定复训计划

## 目标

帮助候选人从“会背答案”变成“真正理解并能够表达”。
