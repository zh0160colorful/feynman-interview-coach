# Contributing Guide

Thank you for contributing to Feynman Interview Coach.

## Contribution Principles

This project focuses on improving interview learning through:

- Feynman learning methodology
- Adaptive questioning
- Interview simulation
- Feedback-driven improvement

## Before Contributing

Please ensure changes:

1. Improve the coaching experience
2. Keep the learning loop clear
3. Avoid turning the project into a simple answer generator
4. Preserve the principle of understanding over memorization

## Suggested Contributions

- New interview training scenarios
- Better evaluation frameworks
- More examples
- New learning workflows
- Documentation improvements
