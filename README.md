# Feynman Interview Coach

[English](README.md) | [简体中文](README.zh-CN.md)

An AI interview coaching skill powered by the Feynman Technique.

The goal is not to generate memorized answers, but to help candidates understand, practice, evaluate, and improve through adaptive interview training.

## Overview

Feynman Interview Coach helps candidates build real interview ability instead of memorizing model answers.

通过费曼学习法，将面试训练从“背答案”转变为：

理解 → 表达 → 追问 → 纠错 → 复训

## Core Loop

Assessment → Feynman Explanation → Active Recall → Interview Practice → Evaluation → Retraining

## Language Support

The Skill supports bilingual interview training:

- Chinese ↔ English translation
- Interview answer translation
- Professional expression optimization
- Bilingual mock interviews
- Terminology explanation

## Goal

Don't memorize the answer. Understand the idea deeply enough to answer different versions of the question.
